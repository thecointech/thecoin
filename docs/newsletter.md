### How to write the newsletter

Once it's written and in prismic:
 - Use Chrome
 - Open the newsletter article in localhost
 - SnipCSS on the article itself
 - Download zip
 - Open downloaded html in code
 - Clean "back" button, "date" and "related" sections
 - Fix any image URLs
 - Copy styles into <head>
 - Copy content into CSS Inliner.  https://automattic.github.io/juice/ is the one that worked best (this time).
 - Save to HTML file
  - NOTE: I had to keep "<html><body>" tags.
  - NOTE: Any variables may need updating: eg `color: var(--thecoin-primary)`
  - NOTE: Check hard-coded widths etc
 - Create new campaign in Mailjet
 - Use HTML template
 - Copy in HTML
 - CHECK MOBILE VIEW
 - done
